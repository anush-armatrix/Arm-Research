Multi-pass arc welding · planner specification · ASD-STE100 · 6 Oct 2026

Draw, Match, Rescan

This page specifies the planner for a multi-pass arc weld. Use a fill planner and a bead matcher. Scan the groove after each pass. The bead model is the simulator or f v2 (§3).

Decision

Do not use the action-first design or the target-first design as written. Use these parts:

  • The fill planner makes a geometric plan for the full groove. It sends only the position x* and the area A* of the next bead.
  • The bead matcher selects the settings for that bead. It uses one step of the bead model. If no sample is legal, it tells the planner.
  • The bead model is the physics simulator if the simulator is fast enough. If not, use f v2 (§3).

After each pass, scan the groove. Then use the parts again on the measured surface. Keep the controller from Plan, Weld, Rescan §9.

§2Architecture

Ordinary code · new

Fill planner

  • Makes a list of all legal fill keys. A fill key gives the number of beads in each layer. Example: [2,3,3] is 2 beads, then 3, then 3.
  • Keeps only the bead areas that the machine can deposit (area equation). Takes the bead width for each area from the corpus (lookup table).
  • Gives each fill key a geometric score against the measured cross-section. It does not call the bead model.
  • Ranks with a fixed rule: the fewest passes, then the fewest layers. Most defects occur at arc starts and arc stops.
  • Sends x* and A* of the next bead from the best fill key. If the matcher returns "infeasible", sends the next bead of the next fill key.
  • Runs again after each scan.
in: measured groove (full cross-section, absolute coordinates)
out: x*, A* of the next bead
Ordinary code · new

Bead matcher

  • Samples 1024 sets of current I, voltage U and torch position y, with y near x*.
  • Calculates travel speed from the area: v_t = κ·I / A*. Calculates wire feed from current. Each sample has the correct area.
  • Removes each sample outside the qualified box. The qualified box is also the training box.
  • Sends all samples to the bead model in one batch. Makes each surface with the reconstruction R.
  • Removes each sample if its predicted bead centre is more than δx from x*. Removes each sample with an edge angle above 90° minus the margin, or with a re-entrant surface.
  • Selects the sample that gives the smoothest surface. If no sample remains, returns "infeasible".
in: x*, A*; measured 16 mm window centred on the torch of each sample
out: settings a_k = (I, U, v_t, y) and v_f, or "infeasible"
Ordinary code · as designed

Controller

  • Calculates the residual: scan minus prediction.
  • Smooth and wide residual: distortion. Replan.
  • Flat residual with the same sign at each pass: bias of the bead model. Replan.
  • Sharp and local residual: defect. Flag it.
  • Stops the weld if a measured edge angle is 90° or more.
  • Stops the weld and tells an operator if no fill key is feasible.
in: scan and last prediction
out: replan, flag or stop

Area equation

The bead area comes from the knob settings. No model is necessary.

A = A_wire · v_f / v_t metal for each unit length of seam v_f = κ · I / A_wire current sets wire feed ⇒ A = κ · I / v_t multiply by deposition efficiency if spatter is large planner: A ∈ [ κ·I_min / v_t,max , κ·I_max / v_t,min ] the planner uses only these areas matcher: v_t = κ · I / A* the matcher samples I, U, y; v_t follows

Hand-off between the planner and the matcher

The fill planner uses geometric bead templates. It does not know which beads the bead model can make on the current surface. The matcher knows this. Thus the planner must not send a bead shape. It sends only the values that it knows exactly: the position x* and the area A*.

The matcher sets the bead shape. The bead model shows where each sample bead goes on the surface, for example how far a bead moves down a slope. The matcher keeps a sample only if its predicted bead centre is within δx of x*. Start with δx = 1 mm, the specification.

From the samples that remain, the matcher selects the smoothest surface: the smallest ∫ (s″)² dx in the window. A smooth surface gives the next bead a good base. This criterion uses the heights, which are the most accurate output of a bead model.

for key in planner.ranked_fill_keys(scan): # geometry only, best first x_star, area_star = key.next_bead() # the only hand-off a = matcher.select(scan, x_star, area_star) # None if no sample passes if a is not None: break else: controller.stop("no feasible fill key") # tell an operator matcher.select: 1. sample I, U, y # y near x* 2. v_t = κ·I / A*, v_f = κ·I / A_wire 3. remove samples outside the qualified box 4. bead model → beads → R → surfaces # one batch 5. remove: |centre − x*| > δx, edge angle > 90° − margin, re-entrant surface 6. return the sample with the smallest ∫ (s″)² dx, or None

A rejected fill key costs one batch of the bead model. Do not add a separate step between the planner and the matcher. That step must use the bead model over the full build, and chained predictions accumulate error. Fill keys with more passes are lower in the rank. Thus "add a pass" and "make a new layer plan" occur in this loop, not in the controller.

If the §7 test shows many rejected fill keys for each pass, add a bead library. A bead library is a set of simulator beads on standard surfaces, made off-line. The planner then uses these beads as templates.

Scan after each pass

A scan is one laser sweep. It takes seconds. The cooling time between passes is minutes (Plan, Weld, Rescan §9.5). Thus a scan after each pass adds almost no time. With this scan, the bead model always starts from a measured surface. It does not use its own output as input. Thus its error cannot accumulate in a plan.

§3Bead model: f v2

The bead model predicts the bead that a set of settings makes on a given surface. The matcher calls it. This design uses f v2: the current network f with one correction for each measured defect. f v2 keeps the two branches of f, its bias term and its selection rule.

Accuracy requirement

f v2 learns from the simulator. Thus it cannot be more accurate than the simulator against real beads.

simulator vs real beads 0.36 mm Plan, Weld, Rescan, measured on real cross-sections specification for each pass 1.00 mm total² = model² + simulator² independent errors ⇒ model error vs simulator ≤ √(1² − 0.36²) = 0.93 mm f today 1.18 mm fails

Reasons for each part

  • Torch-centred window. The corpus windows already have their centre at the torch. Thus a position in the window is a position relative to the arc. The torch-placement input is not necessary. Before you remove it, examine what it measures.
  • Relative heights. The subtraction of s(y) removes the layer height. The bead shape depends on the local surface shape, not on the layer height.
  • Heat input as an input. U·I/v_t controls the size of the hot region. The network does not have to learn this product.
  • FiLM. The settings change how each block reads the surface. Example: a high heat input makes a wide region important. FiLM gives this product directly. At the start, FiLM is the identity. Thus training starts from a plain CNN.
  • Flatten, not global pooling. Global pooling removes the position of each feature. The bead centre and the edges depend on that position. The 1×1 readout decreases the channels to 16. Thus the flatten has 336 values, not 1,344.
  • Receptive field. The convolution blocks see 4.3 mm. The trunk after the flatten sees the full 16 mm window. Thus a wall at 7 mm from the torch has an effect on the bead.
  • GELU. GELU gives a gradient for negative inputs. Plain ReLU gives zero. Plain ReLU units stopped and cut the surface branch in 22 of 36 runs.
  • Edge outputs. The centre c and the half-width softplus(ŵ) make x_l < x_r for all outputs. Thus R always receives a valid bead.
  • Angle head. The edge angle depends on the surface at the edge. The angle head reads only the features and the measured slope at the two edges. With the stop-gradient, the angle loss does not change the edges.
  • Slope span ±1 mm. The scan noise is 0.16 mm. On ±1 mm, the slope noise is 0.058, which is 3.3°. A shorter span gives more noise. A longer span is less local.
  • No area output. The area equation is exact. R scales the heights to this area.

Loss

errors e_η = η̂ − η, e_x = (x̂_l − x_l, x̂_r − x_r), e_θ = θ̂ − θ Huber H_δ(e) = ½e² if |e| ≤ δ, else δ·(|e| − ½δ) terms L_η = mean H_δ(e_η) δ = 0.16 mm L_x = mean H_δ(e_x) δ = 0.16 mm L_θ = mean H_δ(e_θ) δ = 2° L_b = ( mean e_η )² bias term of the current trainer L_p = mean H_δ( Δŷ − Δy ), Δy = y(s′, a) − y(s, a) pairs: same a, two surfaces total L = L_η/L_η⁰ + L_x/L_x⁰ + L_θ/L_θ⁰ + L_b/σ_η² + L_p/L_p⁰ L_k⁰ = value of L_k for a model that predicts the training mean σ_η² = variance of η on the training split

Each normalized term is 1 for a model that predicts the training mean. Thus no term controls the sum because of its units. Do not tune these weights unless a gate fails.

In a pair, the settings are the same. Thus the settings effect cancels in the difference, and only the surface effect remains. A surface-blind model predicts a zero difference. For that model, L_p/L_p⁰ = 1. Thus the pair term also detects a surface-blind model in training.

All loss terms use the outputs before R. Thus R does not have to be differentiable.

Pipeline

Data:

  1. Make base samples with the data generator and the simulator. Use surfaces from simulated builds. Sample the settings in the qualified box.
  2. For each base sample, change the surface 2 to 4 times at the same settings: slope, wall distance, bump. Label each change with the simulator.
  3. Crop a 161-point window with its centre at the torch. Subtract the height at the torch.
  4. Add Gaussian noise with σ = 0.16 mm to each input profile. Do not add noise to the labels.
  5. Add the mirror image of each sample. Mirror the gravity vector. Exchange the left and right outputs.
  6. Split by build and by groove geometry, not by pass. Keep one groove family for an out-of-distribution test.
  7. Calculate the settings mean and standard deviation on the training split only.

Training:

  1. Set FiLM to the identity: W_b = 0 and c_b = 0.
  2. Train with AdamW and the start values below.
  3. After each epoch, calculate the validation loss with the bias term. Keep the best epoch.
  4. Stop after 20 epochs with no improvement.
  5. Train 5 seeds. Report the mean and a 95% confidence interval for each gate metric.
  6. Do the gates on the held-out builds and on the held-out groove family.
  7. Plot the validation error against the data size. If the error still decreases, make more data and train again.
  8. Run the matcher in the simulator. Label its selected samples with the simulator. Add them to the training data. Train again.

The last step is necessary because the matcher selects the inputs where the model error is most favourable. The new labels correct the model at those inputs.

Inference in the matcher:

  1. For each sample, crop the window from the scan at its torch position y. Subtract s(y). Do all samples in one batch.
  2. Standardize the settings with the training statistics.
  3. Run all ensemble members in one batch. Use one member in mode B.
  4. Use the mean output of the members. Calculate the spread: the largest standard deviation of the 81 heights.
  5. Remove each sample with a spread above τ.
  6. Calculate A with the area equation. Make Δs with R. Add Δs to the scan.
  7. Send the predicted surfaces to the matcher limits.

To set τ, plot the validation height error against the spread. Set τ at the spread where the error becomes 0.93 mm.

Unit tests

  1. Area: the area of the R output is equal to κ·I / v_t.
  2. Edges: x_l < x_r for 100,000 random inputs.
  3. FiLM at start: the output with FiLM is equal to the output without FiLM.
  4. Window: u(0) = 0 for each crop.
  5. Mirror: after training, the prediction for a mirrored input agrees with the mirrored prediction within the G1 limit.
  6. Surface use: L_p/L_p⁰ < 1 on validation pairs.

Computation time is not a constraint. Each chained prediction adds error from the model. Fewer chained predictions give less error.

The fill term cannot see bead position

The action-first cost uses the deficit D below the fill line g. The reconstruction R makes each bead area equal to the predicted area A.

D(s) = ∫ max(0, g − s) dx if s + Δs ≤ g at all x: D(s + Δs) = ∫ (g − s − Δs) dx = D(s) − ∫ Δs dx = D(s) − A

Thus D decreases by A at all bead positions if no bead goes above g. Over 5 passes, the fill term is the sum of 5 areas. The area equation gives these areas without f. The appendix shows a numerical check.

Only two other parts of the action-first cost use f:

  • The roughness after 5 chained predictions.
  • The edge-angle limits. The edge-angle error of f is 12.31°. A constant prediction gives 12.63°.

The start point of the CEM search sets most bead positions. The action-first design takes this start point from a placement heuristic: left, right, centre, then up as the groove fills. This heuristic is a fill plan. This design replaces it with a fill plan for the full groove.

The horizon of 5 sets the scan interval, not the plan length

The action-first design calculates H* = (σ/μ)² = 12.3. At this pass count, the bias of f becomes larger than the random error in the estimated surface. This value sets the scan interval. It does not set the plan horizon.

The plan horizon must cover the full effect of a decision. This effect can continue for one full layer. Example: a flat layer centre leaves a narrow, steep slot at the sidewall. Two or three passes later, the bead in that slot cannot wet the two walls. Its edge angle becomes more than 90°.

A 5-pass horizon sees this failure only if it occurs in those 5 passes. A full-groove plan always sees it.

Model gradients are not necessary

Two Ways §05 rejects target-first because target-first uses the gradients of f. That argument applies only to a gradient solver. When the area equation sets v_t, the inverse has 3 free numbers. 1024 samples cover 3 dimensions well. The samples use only the values of the model.

The surface-blind argument in Two Ways §05 applies to the two designs equally. The inverse uses gradients with respect to the settings, not the surface. A surface-blind model gives incorrect beads in the two designs. Thus gate G3 (§3) is necessary for all designs.

Scale

  • Long builds. The plan covers the full groove for all pass counts. The work for each pass is constant. The model does not chain. Thus 60 passes are not more difficult for the model than 6 passes.
  • New groove shapes. Asymmetric V-grooves and crown shapes (Two Ways §08) change only the planner input. The bead model sees only a 16 mm local window. f v2 must have training data for new local shapes, for example a new wall angle. The simulator (mode A) does not.
  • Along the seam. One pass goes along the full seam. Thus the fill key is the same along the seam. The target area can change at each station.
  • Size of the fill-key list. The list has approximately 4,801 fill keys at this time. The planner scores them without the model. If a large groove gives millions of fill keys, replace the list with dynamic programming, one layer at a time.

Weld quality

  • Fill. The planner uses only areas that the knobs can deposit. The matcher sets the target area exactly. Thus the plan and the bead have the same metal volume.
  • Lack of fusion. Three barriers prevent it. The plan prevents narrow slots. The matcher removes predicted edge angles above 90° minus the margin. The controller stops the weld at a measured edge angle of 90° or more.
  • Bias. On a real 31-pass weld, a scan after each 5th bead decreased the accumulated area error from −11.54 mm² to −1.37 mm². A scan after each pass must give an equal or better result. This is a prediction. The §7 test measures it.
  • No feasible fill key. The controller stops the weld and tells an operator.

§8Build sequence

Do the phases in this sequence. Do not start a phase before the gate of the previous phase passes.

  1. Measure the simulator time

    Measure t_sim for one bead on the target hardware. Select mode A, B or C (§3).

    gate: t_sim is measured; the mode is selected

  2. f v2

    Train f v2 and the linear baseline. Do the unit tests and the gates (§3).

    gate: f v2 passes G1 to G5, and G6 in mode B

  3. Fill planner

    Make the list. Apply the area limits. Score each fill key. Rank with the fixed rule.

    gate: the area stays constant; a groove with a known solution gives the correct fill key; each planned bead is possible

  4. Bead matcher and hand-off

    Sample. Calculate v_t from the area. Call the bead model one time. Apply the limits. Select the smoothest surface. Return "infeasible" if no sample remains.

    gate: matched beads are in the 1 mm specification; an impossible target makes the planner send the next fill key

  5. Closed loop in the simulator

    Do the §7 test.

    gate: C is equal to or better than B for lack-of-fusion edges and pass count

  6. Controller

    Add the residual classes and the stop rules.

    gate: the controller classifies injected distortion, bias and defect residuals correctly
