This page specifies the planner for a multi-pass arc weld. Keep the bead model f with no change. Replace the 5-pass search with a fill planner and a bead matcher. Scan the groove after each pass.

Decision

Do not use the action-first design or the target-first design as written. Use these two parts:

  • The fill planner makes a geometric plan for the full groove. The plan sets the layers, the beads in each layer, and the position and area of each bead.
  • The bead matcher selects the settings for the next bead. It uses one step of f.

After each pass, scan the groove. Then use the two parts again on the measured surface. Keep the controller from Plan, Weld, Rescan §9 with no change.

§2Architecture

Ordinary code · new

Fill planner

  • Makes a list of all legal fill keys. A fill key gives the number of beads in each layer. Example: [2,3,3] is 2 beads, then 3, then 3.
  • Keeps only the bead areas that the machine can deposit (see the area equation).
  • Gives each fill key a geometric score against the measured cross-section. It does not call f.
  • Selects with a fixed rule: the fewest passes, then the fewest layers. Most defects occur at arc starts and arc stops.
  • Runs again after each scan. The plan always agrees with the measured groove, also after distortion.
in: measured groove (full cross-section, absolute coordinates)
out: list of target beads; the matcher uses only the first
Ordinary code · new

Bead matcher

  • Samples 1024 sets of current I, voltage U and torch position y.
  • Calculates travel speed from the target area: v_t = κ·I / A*. Calculates wire feed from current. Each sample has the correct area.
  • Removes each sample that is outside the qualified box.
  • Sends all samples to f in one batch. Makes each surface with the reconstruction R.
  • Removes each sample with a predicted edge angle above 78° (90° minus a 12° margin). Removes each sample with a re-entrant surface.
  • Selects the sample with the predicted surface nearest to the target surface. Optional: sample again near the best 10%.
in: target bead; measured 16 mm window at the torch position of each sample
out: settings a_k = (I, U, v_t, y) and wire feed v_f
Ordinary code · as designed

Controller

  • Calculates the residual: scan minus prediction.
  • Smooth and wide residual: distortion. Replan.
  • Flat residual with the same sign at each pass: bias of f. Replan.
  • Sharp and local residual: defect. Flag it.
  • Stops the weld if a measured edge angle is 90° or more.
  • No legal settings: the controller first adds a pass. Next, it makes a new fill plan. Last, it stops and tells an operator.
in: scan and last prediction
out: replan, flag or stop

Area equation

The bead area comes from the knob settings. No model is necessary.

A = A_wire · v_f / v_t metal for each unit length of seam v_f = κ · I / A_wire current sets wire feed ⇒ A = κ · I / v_t multiply by deposition efficiency if spatter is large planner: A ∈ [ κ·I_min / v_t,max , κ·I_max / v_t,min ] the planner uses only these areas matcher: v_t = κ · I / A* the matcher samples I, U, y; v_t follows

Scan after each pass

A scan is one laser sweep. It takes seconds. The cooling time between passes is minutes (Plan, Weld, Rescan §9.5). Thus a scan after each pass adds almost no time. With this scan, f always starts from a measured surface. f does not use its own output as input. Thus its error cannot accumulate in a plan.

Computation time is not a constraint. The old search takes milliseconds. Each chained prediction adds error from f. Fewer chained predictions give less error.

The fill term cannot see bead position

The action-first cost uses the deficit D below the fill line g. The reconstruction R makes each bead area equal to the predicted area A.

D(s) = ∫ max(0, g − s) dx if s + Δs ≤ g at all x: D(s + Δs) = ∫ (g − s − Δs) dx = D(s) − ∫ Δs dx = D(s) − A

Thus D decreases by A at all bead positions if no bead goes above g. Over 5 passes, the fill term is the sum of 5 areas. The area equation gives these areas without f. The appendix shows a numerical check.

Only two other parts of the action-first cost use f:

  • The roughness after 5 chained predictions.
  • The edge-angle limits. The edge-angle error of f is 12.31°. A constant prediction gives 12.63°.

The start point of the CEM search sets most bead positions. The action-first design takes this start point from a placement heuristic: left, right, centre, then up as the groove fills. This heuristic is a fill plan. This design replaces it with a fill plan for the full groove.

The horizon of 5 sets the scan interval, not the plan length

The action-first design calculates H* = (σ/μ)² = 12.3. At this pass count, the bias of f becomes larger than the random error in the estimated surface. This value sets the scan interval. It does not set the plan horizon.

The plan horizon must cover the full effect of a decision. This effect can continue for one full layer. Example: a flat layer centre leaves a narrow, steep slot at the sidewall. Two or three passes later, the bead in that slot cannot wet the two walls. Its edge angle becomes more than 90°.

A 5-pass horizon sees this failure only if it occurs in those 5 passes. A full-groove plan always sees it.

Gradients of f are not necessary

Two Ways §05 rejects target-first because target-first uses the gradients of f. That argument applies only to a gradient solver. When the area equation sets v_t, the inverse has 3 free numbers. 1024 samples cover 3 dimensions well. The samples use only the values of f.

The surface-blind argument in Two Ways §05 applies to the two designs equally. The inverse uses gradients with respect to the settings, not the surface. A surface-blind f gives incorrect beads in the two designs. Each scan corrects the two designs in the same way. Thus the branch audit (§5) is necessary for all designs.

Scale

  • Long builds. The plan covers the full groove for all pass counts. The work for each pass is constant. f does not chain. Thus 60 passes are not more difficult for f than 6 passes.
  • New groove shapes. Asymmetric V-grooves and crown shapes (Two Ways §08) change only the planner input. f sees only a 16 mm local window. f must have training data for new local shapes, for example a new wall angle. This is true for all designs.
  • Along the seam. One pass goes along the full seam. Thus the fill key is the same along the seam. The target area can change at each station. The fast loop (each 25 mm, 9–14 s look-ahead) can call the same matcher.
  • Size of the fill-key list. The list has approximately 4,801 fill keys at this time. The planner scores them without f. The time limit is the cooling time (minutes). If a large groove gives millions of fill keys, replace the list with dynamic programming, one layer at a time.

Weld quality

  • Fill. The planner uses only areas that the knobs can deposit. The matcher sets the target area exactly. Thus the plan and the bead have the same metal volume.
  • Lack of fusion. Three barriers prevent it. The plan prevents narrow slots. The matcher removes predicted edge angles above 78°. The controller stops the weld at a measured edge angle of 90° or more.
  • Bias. On a real 31-pass weld, a scan after each 5th bead decreased the accumulated area error from −11.54 mm² to −1.37 mm². A scan after each pass must give an equal or better result. This is a prediction. The §7 test measures it.
  • No legal settings. The controller uses its escalation steps. The last step is: stop and tell an operator.

§5Checks before use

Do these checks before you use f in a planner.

  • Make sure that f sees the groove.

    22 of 36 trained checkpoints do not see it. A flat groove changes their prediction by less than 0.01 mm. The specification is approximately 1 mm.

    Test: make the groove flat. The prediction must change by much more than 0.01 mm.

  • Make sure that the attention gate can follow the torch.

    Plot the gate output at different torch positions. A per-position sigmoid of a linear function cannot make a window that moves with the torch.

    If the gate does not move with the torch, use a small MLP or a parametric window.

  • Make sure that the frames agree with training.

    Each training window has its centre at the torch of its pass. Put the window of each sample at the torch position of that sample.

    Examine the "torch placement" input. If it is relative to the window centre, it is approximately zero in all training data.

  • Make sure that each planned bead is possible.

    The area equation sets the area. Find the bead width for each area in the 6,163 corpus profiles. Use a lookup table, not a model.

  • Measure the cost of the 12° margin.

    A 78° limit can add passes. Measure the number of added passes in the §7 test.

  • Keep all samples in the training box.

    An optimizer on f finds the errors of f.

§8Build sequence

Do the phases in this sequence. Do not start a phase before the gate of the previous phase passes.

  1. Audit f

    Do the branch audit and the gate plot (§5). Select a checkpoint that sees the groove.

    gate: a flat groove changes the prediction by much more than 0.01 mm

  2. Fill planner

    Make the list. Apply the area limits. Score each fill key. Select with the fixed rule.

    gate: the area stays constant; a groove with a known solution gives the correct fill key; each planned bead is possible

  3. Bead matcher

    Sample. Calculate v_t from the area. Call f one time. Apply the limits. Select the nearest sample.

    gate: for simulator beads with known settings, the matched bead is in the 1 mm specification. Test the bead, not the settings. Different settings can give the same bead.

  4. Closed loop in the simulator

    Do the §7 test.

    gate: C is equal to or better than B for lack-of-fusion edges and pass count

  5. Controller

    Add the residual classes and the escalation steps, as designed.

    gate: the controller classifies injected distortion, bias and defect residuals correctly
